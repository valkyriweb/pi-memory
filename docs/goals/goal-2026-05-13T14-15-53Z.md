   ```                                                                                                         
     - tools: ToolA×N, ToolB×M, ...                                                                            
     - files: path1, path2 (top 5 by edit count)                                                               
     - first_user: "<truncated ~200 chars>"                                                                    
     - last_assistant: "<truncated ~200 chars>"                                                                
   ```

 Acceptance criteria                                                                                           
                                                                                                               
 - pi-memory extension loads cleanly in pi without errors.                                                     
 - System prompt diff shows TYPES_SECTION + WHAT_NOT_TO_SAVE + format spec injected; no daily-log/MEMORY.md    
   content injected.                                                                                           
 - No memory_write / memory_read / scratchpad tools registered (verify via /tools listing).                    
 - Manual scratch session: user says "remember that I prefer X" → main agent writes                            
   ~/.pi/agent/memory/profile/user_<slug>.md with valid frontmatter AND updates profile/MEMORY.md index;       
   transcript shows ● Saved 1 memory inline.                                                                   
 - Manual scratch session: 5-message conversation with one substantive design decision, agent does NOT         
   inline-save → turn_end fires forked extraction → extraction writes a memory and transcript shows ● Saved    
   from background fork.                                                                                       
 - Manual scratch session: trivial 1-message chat → turn_end fork either skips (no save-worthy content) OR     
   writes nothing; no memory files created.                                                                    
 - Trivial session shutdown → no journal entry (fails substantive gate).                                       
 - Substantive session shutdown with no memory writes → exactly one structured journal entry appended to       
   today's journal file.                                                                                       
 - Substantive session shutdown WITH memory writes → no journal entry (mutex skip).                            
 - Journal entries are deterministic — no None. blocks possible by construction (no LLM in the path).
