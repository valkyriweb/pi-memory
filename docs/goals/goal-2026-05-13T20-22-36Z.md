# Goal: Migrate existing pi-memory v1 data to v2 typed format                                               
                                                                                                               
   ## Scope                                                                                                    
   One-off data migration. Take the existing ~/.pi/agent/memory/ tree (v1 shape:                               
   MEMORY.md + daily/*.md + SCRATCHPAD.md + qmd index) and produce a clean v2                                  
   tree (typed frontmatter files under profile/ and project/<slug>/, plus                                      
   journal/ for raw history).                                                                                  
                                                                                                               
   This is a data goal, not a code goal. Output is reviewed markdown files,                                    
   not a PR.                                                                                                   
                                                                                                               
   ## Read first                                                                                               
   - ~/Projects/testing/pi-memory/design-v2.md (sections "Migration plan" and "Memory file format")            
   - ~/Projects/testing/dream-memory-harness/README.md                                                         
   - ~/Projects/testing/dream-memory-harness/src/store.ts (resolveProjectSlug, inbox/canonical layout)         
                                                                                                               
   ## Inputs                                                                                                   
   - ~/.pi/agent/memory/ — v1 tree (do NOT modify in place; copy first)                                        
   - ~/obsidian/dream-memory/memory/ — current dream-memory tree (may already                                  
     have profile/ + project/<slug>/ content; this is the merge target)                                        
                                                                                                               
   ## Steps                                                                                                    
                                                                                                               
   ### 1. Snapshot                                                                                             
   - cp -r ~/.pi/agent/memory ~/.pi/agent/memory-archive-2026-05-13/

   - Verify both archives exist before touching originals.                                                     
                                                                                                               
   ### 2. Prune v1 daily logs into a clean inbox-ready bundle                                                  
   Work in a scratch dir (e.g. /tmp/pi-memory-migration/).                                                     
                                                                                                               
   For each ~/.pi/agent/memory-archive-2026-05-13/daily/YYYY-MM-DD.md:                                         
   - Strip <!-- HANDOFF ... --> blocks (regex; they're near-duplicate snapshots, almost no signal).            
   - Strip ## Session Summary blocks where all four sections (Decisions / Lessons / Notes / Follow-ups) are    
 "None."                                                                                                       
   - Strip empty sections.                                                                                     
   - Drop the file entirely if nothing remains.                                                                
   - Drop SCRATCHPAD.md entirely (not part of memory).                                                         
                                                                                                               
   Save pruned output to /tmp/pi-memory-migration/inbox/<date>.md.                                             
                                                                                                               
   Report: original line count vs pruned line count per file.                                                  
                                                                                                               
   ### 3. Port the existing MEMORY.md                                                                          
   - Read ~/.pi/agent/memory-archive-2026-05-13/MEMORY.md.                                                     
   - Classify each section/note into user | feedback | project | reference.                                    
   - For each classified item, emit a typed file under                                                         
     /tmp/pi-memory-migration/staged/profile/<type>_<slug>.md                                                  
     with full frontmatter (name, description, type, originSessionId: "migration-2026-05-13").                 
   - Build /tmp/pi-memory-migration/staged/profile/MEMORY.md as the index.                                     
                                                                                                               
   This is an LLM-assisted classification step. If using dream-memory-harness's                                
   classifier, point it at the pruned content. Otherwise do it by hand —                                       
   MEMORY.md is small enough.                                                                                  
                                                                                                               
   ### 4. Dream-port the pruned daily logs (optional, second pass)                                             
   If dream-memory-harness supports a one-off "consolidate this directory as                                   
   inbox" mode:                                                                                                
   - Point it at /tmp/pi-memory-migration/inbox/.                                                              
   - Run a single batch.                                                                                       
   - Output goes to /tmp/pi-memory-migration/staged/ alongside step 3's output.                                
   - Review the result.                                                                                        
                                                                                                               
   If that mode doesn't exist, skip — step 3 is enough for the static MEMORY.md                                
   content, and the daily logs were mostly noise anyway.                                                       
                                                                                                               
   ### 5. Manual review                                                                                        
   - Open /tmp/pi-memory-migration/staged/.                                                                    
   - Read every typed file. Keep what's good, edit what needs editing, delete                                  
     what's wrong or duplicative.                                                                              
   - Reconcile against ~/obsidian/dream-memory/memory-archive-2026-05-13/ —                                    
     prefer dream-memory entries when they already cover the same topic                                        
     (they're cleaner).                                                                                        
                                                                                                               
   ### 6. Promote                                                                                              
   Once reviewed:                                                                                              
   - Merge staged content into ~/obsidian/dream-memory/memory/ (the live tree                                  
     pi-memory v2 + dream-memory-harness both read from).                                                      
   - Build the final profile/MEMORY.md index from the union.                                                   
   - Initialize ~/.pi/agent/journal/ as empty (pi-memory v2 writes there going                                 
     forward; nothing to backfill).                                                                            
                                                                                                               
   ### 7. Decommission v1 paths                                                                                
   - rm ~/.pi/agent/memory/SCRATCHPAD.md                                                                       
   - rm -rf ~/.pi/agent/memory/daily/                                                                          
   - Keep ~/.pi/agent/memory/MEMORY.md for now (pi-memory v2 doesn't read it;                                  
     remove after 30 days).                                                                                    
   - Drop the qmd index for pi-memory v1's collection if any.                                                  
   - Keep both archives (~/.pi/agent/memory-archive-2026-05-13/ and                                            
     ~/obsidian/dream-memory/memory-archive-2026-05-13/) for ~30 days, then                                    
     delete.
